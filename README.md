# package:lepic

## TL;DR

Dart bindings for the LEPIC wallet engine, generated by flutter_rust_bridge 2.13.0 from
`crates/lepic-ffi`. The app creates one `LepicRuntime`, gives each wallet an `AppSecretStore`
over its secure storage, and calls `EpicWallet` methods, which return Futures and Streams. Every
failure is a thrown `WalletError` with a stable numeric code. Seeds and keys never leave Rust.
Native libraries for Android and iOS are wired in by task U-03; until then the tests load the
Linux library directly.

## Use

```dart
import 'package:lepic/lepic.dart';

await RustLib.init();
final runtime = LepicRuntime(logLevel: LogLevel.info);
runtime.logs().listen((entry) => debugPrint('${entry.level} ${entry.message}'));

final store = lepicSecretStore(myFlutterSecureStorageAdapter); // implements SecretStore
final wallet = await EpicWallet.create(
  runtime: runtime,
  config: WalletConfig(
    dataDir: dir.path,
    chain: Chain.mainnet,
    nodeUrl: 'https://node.example:3413',
    epicboxDomain: 'epicbox.epiccash.com',
    epicboxPort: 443,
  ),
  store: store,
  password: password,
);
```

- `SecretStore` has the same three methods as the app's `secret_store.dart` interface, so the
  app's `PlatformSecretStore` can be passed to `lepicSecretStore` unchanged. LEPIC writes one key,
  `lepic.vault`: the seed encrypted under the wallet password (Argon2id, XChaCha20-Poly1305). Use
  one store per wallet.
- Passwords and recovery phrases cross from Dart because the user types them, and
  `EpicWallet.mnemonic` returns the phrase for the backup screen. Nothing else secret does.
- Dropping (`dispose()`) an `EpicWallet` stops its listener and scan and wipes its keys.
- `EpicWallet.events()` streams session, balance, transaction, sync and transport changes.
- A panic inside LEPIC arrives as `WalletError` with kind `panic`; the runtime stays usable.

## Errors

`WalletError.kind` is a `WalletErrorKind`; `WalletError.code` is its number. Codes never change
meaning. `message` is English for logs and bug reports and holds no secret; do not parse it.

| Code | Kind | Meaning |
|---|---|---|
| 1 | `invalidMnemonic` | The recovery phrase is not valid BIP-39 English. |
| 2 | `wrongPassword` | The password or PIN did not open the vault or sealed text. |
| 3 | `walletAlreadyExists` | The secret store already holds a wallet. |
| 4 | `walletNotFound` | The secret store holds no wallet. |
| 5 | `nodeUnreachable` | The node failed, refused, answered badly, or is behind the wallet. |
| 6 | `notEnoughFunds` | Not enough spendable funds for the amount and fee. |
| 7 | `invalidSlate` | The slate is malformed, of the wrong stage, already handled, or does not verify. |
| 8 | `invalidArgument` | An argument or configuration value was rejected. |
| 9 | `transportFailed` | The Epicbox relay or the slate file failed. |
| 10 | `chainBusy` | Never returned; kept so code written for the earlier binding compiles. |
| 11 | `walletBusy` | A wallet on this directory is already open in this runtime. |
| 12 | `paymentExpired` | The slate's time to live passed. Nothing was signed or posted. |
| 13 | `io` | The wallet database or a file could not be used. |
| 14 | `other` | Anything else. |
| 15 | `locked` | The wallet handle is locked. |
| 16 | `foreignWallet` | The directory holds another wallet's or another network's database. |
| 17 | `secretStore` | The app's secret store failed or holds a damaged vault. |
| 18 | `notPosted` | Finalized and stored, but the node did not accept it. Repost it. |
| 19 | `cancelled` | The operation was cancelled, for example `cancelScan`. |
| 20 | `unsupported` | Not available in this build or configuration, for example Epicbox without a relay. |
| 21 | `panic` | A defect inside LEPIC. The operation was abandoned. |

## Switching the app from its earlier binding

The app's earlier Rust API (`app/rust/src/api`, over `epic-wallet`) maps to this package as
below. Calls on a wallet are methods of `EpicWallet` in both. "New" arguments are the runtime and
the secret store, which the earlier binding kept in process-wide state.

| Earlier call | LEPIC call | Change |
|---|---|---|
| `init_app` (frb init) | none | Nothing global is installed. `RustLib.init()` stays. |
| `generate_mnemonic(word_count)` | `generate_mnemonic(word_count)` | Also accepts 15, 18, 21. |
| `validate_mnemonic(phrase)` | `validate_mnemonic(phrase)` | Same. |
| `wallet_exists(config)` | `wallet_exists(runtime, store)` | Asks the secret store, not the directory. |
| `inspect_slate(json)` | not provided | Needs a slate decoding API in the engine (claim `## Needs`). |
| `validate_epicbox_address(address)` | `validate_epicbox_address(address, chain)` | Chain is explicit. |
| `delete_wallet(config)` | `delete_wallet(runtime, config, store)` | Fails with `walletBusy` at once instead of waiting 20 s. Also deletes the vault. |
| `node_tip(config)` | `node_tip(runtime, config)` | Same result. |
| `EpicWallet::create(config, mnemonic, password)` | `EpicWallet::create(runtime, config, store, mnemonic, password)` | Same semantics. |
| `EpicWallet::open(config, password)` | `EpicWallet::open(runtime, config, store, password)` | Same. |
| `mnemonic(password)` | `mnemonic(password)` | Same. |
| `summary(refresh, minimum_confirmations)` | `summary(refresh)` | Balances use the engine's 10 confirmations, as `epic-wallet info`. |
| `refresh(minimum_confirmations, progress)` | `refresh()` stream | First event 0 %, last 100 % with `summary`. |
| `scan(start_height, progress)` | `scan(start_height)` stream | `ScanProgress` adds `height` and `target_height`. New: `cancel_scan()`. |
| `transactions(refresh)` | not provided | Needs a transaction list in the engine (claim `## Needs`). |
| `enrich_history()` | not provided | App history archive; not an engine feature. |
| `set_tx_note(key, note)` | not provided | App history archive; not an engine feature. |
| `contacts()`, `save_contact`, `delete_contact` | not provided | App address book; keep it in Dart. |
| `export_history()`, `export_history_csv()`, `import_history(data)` | not provided | App history archive; not an engine feature. |
| `estimate_max(minimum_confirmations)` | not provided | Needs a fee estimate in the engine (claim `## Needs`). |
| `estimate_fee(amount, minimum_confirmations)` | not provided | Same. |
| `epicbox_address()` | `epicbox_address()` | `unsupported` when no relay is configured. |
| `create_send_slate(amount, minimum_confirmations)` | `create_send_slate(amount, minimum_confirmations)` | `Slate` adds `tx_id`. New file form: `send_file(amount, minimum_confirmations, path)`. |
| `receive_slate(slate_json)` | `receive_slate(slate_json)` | Same. New file form: `receive_file(path)`, writes `<path>.response`. |
| `finalize_and_post(slate_json)` | `finalize_and_post(slate_json)` | Returns `FinalizedTx`; a refused post fails with `notPosted`. New: `finalize_file(path)`. |
| `send_http(amount, minimum_confirmations, url)` | not provided | LEPIC 1.0 speaks Epicbox and files only. |
| `send_epicbox(amount, minimum_confirmations, address)` | `send_epicbox(amount, minimum_confirmations, address)` | Returns `SentTx`. |
| `start_listener(events)` | `start_listener()` stream | Kinds `connected`, `disconnected`, `received`, `finalized`, `error`, `stopped`. New: `drain_epicbox()` for background work. |
| `stop_listener()` | `stop_listener()` | Same. |
| `listener_running()` | `listener_running()` | Same. |
| `repost_transaction(key)` | `repost_transaction(tx_id)` | Local transaction id instead of the history key. |
| `release_stuck_send(key)` | not provided | The engine never releases a posted send (claim `## Needs`). |
| `cancel_transaction(tx_id)` | `cancel_transaction(tx_id)` | Same. |
| `refresh_with`, `scan_with`, `start_listener_with`, `*_for_tests` | none | Rust-only hooks of the earlier binding. Tests use `MockChain`. |
| `init_logging(dir)` | `LepicRuntime::logs()` stream | The on-disk log ring is task U-04. |
| `log_message(level, tag, message)` | `LepicRuntime::log_message(level, tag, message)` | Target `dart`, tag as a field. |
| `read_log_tail(max_bytes)` | not provided | Task U-04 (log ring and redacted export). |
| `redact_text(text)` | not provided | Task U-04. |
| `generate_wallet_password()` | `generate_wallet_password()` | Same. |
| `seal_password(pin, password)` | `seal_password(runtime, pin, password)` | Argon2id vault instead of PBKDF2; text sealed by the earlier binding does not open. |
| `open_password(pin, sealed)` | `open_password(runtime, pin, sealed)` | Same errors. |

Types: `WalletConfig` keeps its fields; `Chain` has no `usernet`. `WalletError` and
`WalletErrorKind` keep their names and earlier kinds, plus the new ones above. `TxEntry`,
`Contact`, `ImportReport`, `FeeEstimate` and `SlateInfo` have no counterpart yet.

## Develop

Regenerate the bindings after changing `crates/lepic-ffi/src/api`, with the codegen at the
version pinned in the root `Cargo.toml`:

```sh
cd bindings/flutter
flutter_rust_bridge_codegen generate
```

Run the tests on Linux against the library built with the scripted node:

```sh
cargo build -p lepic-ffi --features mock
cd bindings/flutter && flutter test
```

`LEPIC_FFI_LIB` points the tests at another library path. `MockChain` works only in a `mock`
build; in any other build it fails with `unsupported`.
